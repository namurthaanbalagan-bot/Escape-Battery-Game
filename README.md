# Escape-Battery-Game
A fun interactive game where players navigate obstacles and manage power levels to escape before the battery runs
🔋 Escape Battery Game
📌 Project Description

Escape Battery Game is a simple text-based adventure and quiz game developed using Python.

In this game, the player is trapped inside a secret battery laboratory. To escape from the laboratory, the player must solve 5 different levels by answering questions correctly.

Each level contains a question, and the player gets 3 attempts to find the correct answer. Hints are provided when the player gives a wrong answer.

The main goal is to successfully complete all 5 levels and escape from the battery laboratory!

🎮 Game Features
Player name input
5 exciting quiz levels
3 attempts for each level
Hints for incorrect answers
Score calculation (10 points per level)
Game over option
Final escape celebration message
Interactive text-based gameplay
🛠️ Technologies Used
Python 3
Time module

🕹️ How to Play
Enter your player name.
Read the questions displayed in each level.
Enter the correct answer.
You have 3 attempts for each question.
If your answer is wrong, a hint will be provided.
Answer all 5 levels correctly to escape the laboratory.
Your final score will be displayed at the end.
🏆 Levels
Level	Name	Topic
1	Battery Power	Basic Mathematics
2	Secret Number	Number Series
3	Battery Terminals	Battery Knowledge
4	Security Code	Mathematical Operations
5	Final Escape	Electrical Energy
📊 Scoring System
Correct answer: 10 points
Maximum score: 50 points
Each level has 3 attempts.
The game ends if the player fails a level.
